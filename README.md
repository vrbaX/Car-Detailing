# VRB DETAILING

Homepage concept for a car detailing studio in Stříbro, Czech Republic.

## Stack

- React
- Vite
- Tailwind CSS v4
- lucide-react

## Development

Requirements: Node.js 20.19+ (or a compatible newer LTS release).

```bash
npm install
npm run dev
```

Create a production build:

```bash
npm run build
```
